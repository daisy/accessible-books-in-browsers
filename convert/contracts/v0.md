# Web-book UI contract v0

A book stamped `<html data-webbook-contract="0">` guarantees everything listed here. A UI release
(the CSS and JS under `template/src/`, or a remote release on the `v0/` channel) may rely on
these and nothing else. Anything not listed must be feature-detected.

A change that stays within this list is a new release in the `v0` channel. A change that needs
something added, removed or renamed here is contract v1. It ships with a v0→v1 step for
`webbook-upgrader`, which moves existing books to the latest contract without reconverting.

`src/template-contract.ts` checks the converter's side: the hooks it fills in, and that the
template declares contract `0`.

## Scope note

In v0 the reader chrome (toolbars, popovers, settings panel) is written into every generated page.
It is not built by the JS. So most UI changes, such as adding a setting, a toolbar button or a
popover, change the book HTML and need a new contract. Within v0, a release can change styling,
behavior, and any elements the JS itself creates (listed under "Created by the UI" below).

## Document

- `<html lang="…" data-webbook-contract="0">`
- `<head>`:
  - `<title>`
  - `<meta name="webbook-book-id" content="…">` (the book identifier; resume position is keyed on it)
  - The inline appearance script (below)
  - `<link rel="stylesheet" href="src/css/style.css">`
- `<script type="module" src="src/js/main.js">` at the end of `<body>`
- UI assets are at `src/css/` and `src/js/` relative to each page. Pages are flat files in one
  directory (`index.html` is the entry page). The UI does not rely on any other asset path.
- Optional `search-data.json` at the book root contains versioned book search data. Older books may
  omit it; the reader reports that search is unavailable rather than failing.

### Search data — `search-data.json` (optional)

Version 1 is `{ version: 1, lang, pages, passages }`. `pages` contains `{ href, title }` in spine
order. Each passage contains `{ page, heading, text, lang? }`; `page` indexes `pages`, and `lang`
is present only when it differs from the book language. A narrated passage has the cue target's
existing `id`. A non-narrated passage instead has a Web Annotation-style
`selector: { type: "TextQuoteSelector", exact, prefix?, suffix? }`. The browser builds its own
index from this data on first search and resolves text quotes against addressable blocks in
`<main>`.

### Book audio map — `audio-map.json` (optional)

Version 1 is `{ version: 1, duration, pages, chapters }`. `duration` and all times are seconds.
`pages` contains every spine page as `{ href, title, start, duration }`; unnarrated pages have a
zero duration. `chapters` contains ascending top-level TOC positions as `{ title, href, time }`.
When present, the UI enhances the per-page narration slider into a full-book timeline. Older books
without this file retain the per-page slider.

### Inline appearance script (frozen)

This runs before first paint and is baked into every page, so no release can change it. It reads:

| Key | Values | Effect |
|---|---|---|
| `webbook-appearance` | `auto` \| `dark` \| `light` | `webbook-dark` or `webbook-light` class on `<html>` |
| `webbook-font-size` | integer, clamped to 50–200 | `--webbook-main-font-size: N%` on `<html>` |
| `webbook-font-family` | `system-ui` \| `sans-serif` \| `serif` | `--webbook-main-font-family` on `<html>` |
| `webbook-caption-mode` | `'true'` | `webbook-caption-mode` class on `<html>` |

Releases must keep writing these keys with these meanings and value ranges, and CSS must honor
these classes and custom properties.

Caption mode is a per-book setting (`webbook-caption-mode:<book-id>`, below), but this script only
reads the shared `webbook-caption-mode`. The UI sets the shared key to the current book's setting on
every page load, so the script is right for every page after the first one of a newly opened book.

## Content (`<main>`)

- `<main>` holds the page's book content. It is the boundary for structure lookups.
- Elements that narration can target have `id`s.
- Search does not add ids to non-narrated content; it locates those passages from text quote
  selectors at runtime.
- EPUB structural semantics appear as classes `epubtype_<type>` (`:` becomes `_`). The UI relies on:
  - `epubtype_pagebreak` (with `aria-label` holding the page label)
  - `epubtype_footnote`, `epubtype_endnote`, `epubtype_note`, `epubtype_sidebar`
  - `epubtype_table`, `epubtype_list`, `epubtype_figure`
- Plain `table`, `ol`, `ul`, `figure` elements are also treated as escapable structures.
- Heading self-links: `h* > a.webbook[rel=bookmark][href="#<heading id>"]`.
- Entry page only: `section.webbook-title-page` with `img.webbook-title-cover`, `.webbook-title-kicker`.

## Narration

- Optional. On a page with narration there is a single `<audio>` in `#webbook-toolbar` with `src`
  or `source[src]`. On a page without narration the converter removes both `<audio>` and
  `#webbook-audio-controls`.
- One `<track>` child: WebVTT metadata. Each cue's text is JSON `{ "selector": { "type", "value" } }`
  where `type` is `FragmentSelector` (value is an element id) or `CssSelector`.
- Cues are in document order.

## Chrome

All IDs below are present on every page unless marked optional.

### Spine navigation — `nav#webbook-spine-nav`

- `a#webbook-previous-document`: has `href` when a previous page exists. On the entry page it is
  removed (converter output) or has no `href` (hand-authored template). The UI treats "no
  `#webbook-previous-document[href]`" as "this is the entry page."
- `a#webbook-next-document[rel=next]`: has `href` when a next page exists; removed otherwise.
- The UI looks up spine links as `#webbook-spine-nav a[rel=next|prev][href]`. Books converted
  before 2026-10-19 may lack `rel="prev"` (see Known gaps).

### Table of contents — `nav#webbook-toc-nav[popover].webbook`

- `h2#webbook-toc-nav-hd`; optional `a#webbook-cover-link` points to the cover document identified
  by EPUB landmarks or the EPUB 2 guide (it is omitted when the EPUB identifies only a cover image).
  The UI moves this link to the About panel.
- Nested `ol > li > a`. The link for the current page has `aria-current="page"`, but only when a
  link points at the page itself: when every link to a page has a `#fragment`, none is marked. The
  UI marks the entry for the reader's section itself when the TOC or About panel opens.
- In a book narrated in part (some TOC links lead to narrated pages, some don't), each link to a
  narrated page has `data-webbook-narrated` and ends with `span.webbook-narrated-mark` (an
  `aria-hidden` icon and `.sr-only` text ", narrated"). A `p#webbook-toc-narration-key[aria-hidden]`
  before the list explains the icon. A fully narrated or unnarrated book has none of these.

### Top toolbar — `section#webbook-top-toolbar.webbook`

- `button[popovertarget="webbook-search"]`, `button[popovertarget="webbook-menu"]`

### Escape — `div#webbook-escape-container`

- `div#webbook-escape-status[role=status]`: empty at load, always in the DOM (live region)
- `button#webbook-escape-btn[hidden][disabled]` containing `span#webbook-escape-label`

### Resume banner

- `div#webbook-resume-banner[role=status][hidden]`

### Bottom toolbar — `section#webbook-toolbar.webbook`

- `button[popovertarget="webbook-toc-nav"]`, `button[popovertarget="webbook-settings"]`,
  `button[popovertarget="webbook-info"]`
- `div#webbook-audio-controls[role=group]` (optional, see Narration) containing `button#webbook-previous-phrase`,
  `button#webbook-audio-playpause`, `button#webbook-next-phrase`,
  `input[type=range]#webbook-seek`, `span#webbook-time`. Books converted before 2026-11-02 also
  have `datalist#webbook-seek-ticks`, linked from the slider's `list` attribute. It is deprecated:
  the UI removes the slider's `list` attribute and no longer fills the datalist.

### Go to page — `section#webbook-menu[popover].webbook`

- `input#goto-page[list=pages]`, `button#webbook-goto-page-go`
- `datalist#pages` of `option[value][data-href]` (label may differ from value)

### Search — `section#webbook-search[popover].webbook`

- `h2#webbook-search-hd`, `form#webbook-search-form[role=search]`, `input#webbook-search-input`,
  `ol#webbook-search-results[aria-live=polite]`

### About — `section#webbook-info[popover].webbook`

- `img#webbook-cover`, `.webbook-info-body`, `h2#webbook-info-hd`, `dl` of metadata
- `section#webbook-progress` containing `p#webbook-current-page-label`,
  `progress#webbook-reading-progress[max=100]`, `p#webbook-progress-count`
- The UI moves optional `a#webbook-cover-link` here and styles it as `.webbook-cover-page-link`.

### Settings — `section#webbook-settings[popover].webbook`

| Control | Type |
|---|---|
| `#webbook-highlight-auto-toggle` | checkbox |
| `#webbook-color-picker` | color |
| `#webbook-font-size-range` (50–200, step 5), `#webbook-font-size-value`, `#webbook-reset-font-size` | range, text, button |
| `#webbook-font-family-options` (`system-ui`, `sans-serif`, `serif`) | select |
| `#webbook-appearance-options` (`auto`, `dark`, `light`) | select |
| `#webbook-dialog-blur-toggle` | checkbox |
| `#webbook-caption-mode-toggle` | checkbox |
| `#webbook-rate-range` (50–200, step 5), `#webbook-rate-value`, `#webbook-reset-rate` | range, text, button |
| `#webbook-skip-pagebreak-toggle`, `#webbook-skip-footnote-toggle`, `#webbook-skip-note-toggle`, `#webbook-skip-sidebar-toggle` | checkbox |
| `#webbook-resume-toggle` | checkbox |

Also `.sr-only` (used on the settings `legend`).

## Created by the UI (not part of the contract)

The JS creates these, so a release may change them freely:

- `.webbook-popover-close` buttons in each popover
- `section#webbook-caption-view` with `#webbook-caption-text`
- The keyboard shortcuts setting (`#webbook-keyboard-shortcuts-toggle` and its row), added to the
  settings fieldset if the page doesn't already have it
- The "Change keyboard shortcuts" button below that row and
  `section#webbook-keyboard-shortcuts[popover]`, a separate panel with grouped action lists,
  current keys, Change/Remove controls, an individual Restore default control for changed bindings,
  visible and announced two-step conflict warnings for reassignment and restoration, and Reset to
  defaults.
  `#webbook-shortcut-status[role=status]` inside it announces capture instructions, results and
  refusals.
- `#webbook-action-status[role=status].sr-only`, a polite live region outside the popovers for
  narration speed, text size, caption mode and requested time-left announcements
- `button#webbook-continue-playing`, shown when the browser refuses to start narration on a page
  the reader arrived at while listening
- The play/pause icon, search result items
- `p#webbook-search-status[role=status]` above the results list; the UI removes `aria-live` from the
  list itself so only the concise result count is announced
- Classes set at runtime: `.visible` (toolbars), `.open` (popover buttons), `webbook-dark`,
  `webbook-light`, `webbook-caption-mode`, `webbook-dialog-backdrop-blur` on `<body>`
- `::highlight(narration)` and `--webbook-highlight-color`
- `::highlight(search)`, used for matched words after following a result
- `tabindex="-1"` on each narrated element in `<main>` that isn't already focusable, so a screen
  reader's cursor brings keyboard focus with it (used by Play from here)
- `--webbook-font-scale` on `<html>`, the font size setting as a unitless factor
- TOC tree roles, roving `tabindex`, `aria-expanded`, hidden nested groups,
  `.webbook-toc-chevron` pointer controls, and `#webbook-toc-depth-control` with
  `select#webbook-toc-depth`, `div#webbook-toc-find` (a labelled `input#webbook-toc-find-input` and
  `p#webbook-toc-find-status[role=status]`)
- `div#webbook-book-timeline` around the narration slider, containing
  `#webbook-chapter-ticks[aria-hidden=true]`, `.webbook-chapter-tick` marks and
  `#webbook-timeline-label`
- `button#webbook-time-mode` around `#webbook-time`, cycling the visible timeline value between
  elapsed time, chapter time left and book time left

## Reader state (`localStorage`)

Books from different releases, and different books on the same origin, share these keys, so a
release must keep reading values written by earlier v0 releases.

| Key | Values |
|---|---|
| `webbook-appearance` | `auto` \| `dark` \| `light` |
| `webbook-font-size` | integer string, 50–200 |
| `webbook-font-family` | `system-ui` \| `sans-serif` \| `serif` |
| `webbook-caption-mode` | `'true'` \| `'false'`: the setting of the book read most recently, for the inline appearance script |
| `webbook-caption-mode:<book-id>` | `'true'` \| `'false'`: caption mode for that book. A book without one starts with the shared key's value. |
| `webbook-caption-entry` | `'first'` \| `'last'` (one-shot, cross-page): the phrase to start at after stepping across a page boundary, in or out of caption mode |
| `webbook-highlight-auto` | `'true'` \| `'false'` (default true) |
| `webbook-highlight-color` | CSS hex color |
| `webbook-dialog-backdrop-blur` | `'true'` \| `'false'` (default true) |
| `webbook-rate` | integer string, 50–200 |
| `webbook-time-display` | `elapsed` \| `chapter` \| `book` (default `elapsed`) |
| `webbook-skip-pagebreak`, `webbook-skip-footnote`, `webbook-skip-note`, `webbook-skip-sidebar` | `'true'` means skip |
| `webbook-resume-enabled` | `'true'` \| `'false'` (default true) |
| `webbook-keyboard-shortcuts` | `'true'` \| `'false'` (default true) |
| `webbook-keyboard-shortcut-map` | JSON `{ "version": 1, "bindings": { "<action id>": [keySpec, …] } }`; only custom bindings, with `[]` disabling an action. Missing actions use their defaults. Shared across books; malformed data and unknown actions/fields are ignored. |
| `webbook-toc-depth` | `1` \| `2` \| `3` \| `all` (default `all`), shared across books |
| `webbook-resume:<book-id>` | JSON `{ page, elementId?, audioTime?, ts }` |
| `webbook-resume-banner-pending` | `'true'` (one-shot) |
| `webbook-autoplay`, `webbook-autoplay-target` | `'true'`, absolute URL without hash (one-shot) |

Each shortcut `keySpec` stores a physical `KeyboardEvent.code` and exact boolean modifiers, e.g.
`{ "code": "KeyF", "shift": true, "alt": false, "ctrl": false, "meta": false }`.

`sessionStorage`: `webbook-resume-checked`; `webbook-search-highlight` is a one-shot search target
used to preserve matched-word highlighting across a full page load when in-place navigation is
unavailable.

## Known gaps in v0 output

Converter output is what v0 guarantees, even where it differs from the hand-authored template.
Books converted before 2026-10-19 have these defects, which the converter no longer produces:

- `#webbook-previous-document` keeps the template's `hidden` attribute and has no `rel="prev"`. The
  link is invisible and unreachable, and "previous" in caption mode at the start of a page and the
  media-session "previous track" action do nothing.
- The spine links keep the template's `aria-label` ("Next: Chapter 1. …") instead of naming their
  real target. That fails WCAG AA.

Fixing these in the converter doesn't change the contract, but releases can't assume the fix is
present in books that are already converted.

## URLs

- A generated page may represent one chapter of a larger EPUB content document; element ids remain
  unique across all generated pages in the book.
- `#<id>` in the page URL means "position at this element." The UI keeps it updated during
  narration with `history.replaceState`.
- The UI may load another page of the book in place instead of navigating to it: it fetches the
  page, swaps in its `<main>`, `<title>`, `lang`, spine links, TOC `aria-current` and narration,
  and sets the page's URL with `history.pushState`. It does this only for a page in the same
  directory with the same contract, book ID and stylesheets, and loads anything else normally. So
  every page must still work as a complete page on its own, and the URL in the address bar is
  always a real page.
