EPUB to web book converter Beta

Turn an accessible EPUB, including a narrated one, into a web book that reads in any browser, with highlighted narration, search, bookmarks and offline reading.

Before you start

  • Your book stays on this computer. Converting happens in this page; nothing is uploaded.
  • This is a beta. Converted books may need converting again from the EPUB when the format changes, so keep your EPUB files.
  • Preview first. Convert one chapter and read and listen to it here, then convert the whole book. The result is a zip of the web book’s files, to put on any website.
  • Use a computer. Narrated books need more memory than phones and tablets have. Narration takes about 2½ seconds per minute of audio: a 6-hour book takes about 15 minutes.

Converting needs a computer. This device looks like a phone or tablet, which doesn’t have enough memory to convert a book. Open this page on a computer instead.

1 Choose an EPUB

The converter only works with valid EPUBs and can’t validate them in the browser. Check yours first with EPUBCheck.

2 Options

The defaults suit most books.

Reader updates

How the book gets the reader: the toolbars, settings, narration controls and so on. The book’s text never changes.

The book loads the latest reader from this project’s beta channel when it’s online, and uses its own copy when it isn’t, or if the channel is unavailable. The channel’s address may change during the beta.

The book never loads anything from elsewhere. It keeps today’s reader; newer features need converting again.

Narration

This book has no narration, so these don’t apply.

Mono MP3 at 24 kHz and 32 kb/s: quicker to download and save offline. Turn off to keep the narration’s own quality.

Always: smooths the joins between clips, removes low rumble, softens “p” and “b” pops and evens out loudness.

Extra enhancements

Optional, on top of the cleanup. Untick them all to clean up without changing the voice’s tone.

Appearance and pages

Readers can switch each book between their own settings and the book as published.

When every page has the book title as its own title, change the page title to be the first heading on that page.

Where the table of contents points to places inside one document, make a page for each. Untick to keep each document as one page.

Advanced

Pages the EPUB marks as outside the main reading order, such as answer keys or pop-ups.

Leave empty to use the book’s own. A language tag such as en, fr-CA or bn.

Leave empty to use the EPUB’s identifier. Reading positions and bookmarks are kept per book ID, so keep it the same when you convert the book again.

Download the web book (zip)

Unzip it and put the folder on any website, such as GitHub Pages. Books don’t open straight from the files on your computer: browsers block their scripts there.

Part of accessible books in browsers. Converted books follow the EPUB’s own accessibility; this converter doesn’t repair inaccessible books, and its report may include things to review. Not a replacement for running EPUBCheck.
