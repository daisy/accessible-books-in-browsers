EPUB to web book converter Beta

Turn an accessible EPUB, including a narrated one, into a web book that reads in any browser, with highlighted narration, search, bookmarks and offline reading.

Before you start

  • Your book stays on this computer. Converting happens in this page; nothing is uploaded.
  • This is a beta. Converted books may need converting again from the EPUB when the format changes, so keep your EPUB files.
  • Preview first. Convert one chapter and read and listen to it here, then convert the whole book. The result is a zip of the web book’s files, to put on any website.
  • Use a computer. Narrated books need more memory than phones and tablets have. Narration takes about 2½ seconds per minute of audio: a 6-hour book takes about 15 minutes.

Converting needs a computer. This device looks like a phone or tablet, which doesn’t have enough memory to convert a book. Open this page on a computer instead.
